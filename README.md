# City Dash

An endless 3-lane runner for the TV, controlled by your phone.

- **TV / Fire Stick:** open the site in the Silk browser → a QR code and a 4-digit room code appear.
- **Phone:** scan the QR (or open `pad.html` and type the room code) → tilt to change lanes, JUMP / ROLL buttons.

Phone and TV connect peer-to-peer with WebRTC ([PeerJS](https://peerjs.com)); no game server needed.

Built with [three.js](https://threejs.org) r128. Runner model: `Soldier.glb` from the three.js examples (Mixamo).
